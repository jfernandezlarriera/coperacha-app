# coperacha-app

App de [Coperacha](https://coperacha.app): el bot de WhatsApp para colectas en grupo («coperachas»).
Junta los compromisos, cobra sólo si se llega a la meta y cada cobro CoDi va directo a la cuenta de
quien recibe: Coperacha nunca guarda dinero. Proyecto para Hackatón México 2026.

Repo público. Nunca subir secretos, claves ni datos de usuarios.

La landing vive en [`coperacha-landing`](https://coperacha.app) (repo aparte).
